This is an ultrasonic sensor base alert system that goes off when the test object is less than 15cm or 15cm. 
It uses an Arduino Uno, HC-SR04 ultrasonic sensor, buzzer and led.
The ultrasonic sensor sends out an high frequency sound(inaudible to humans) when it detects a sufficient pulse of its trig pin being HIGH-and internally also makes its echo pin HIGH that becomes LOW once the sound returns to its sensor.
When test object is more than 15cm away, the buzzer and LED are off. When it is between 10cm to 15cm away from the sensor, it beeps at a slower speed and the light of the LED is dimmer.
If it is less than 10cm away, the buzzer beeps faster and the light of the LED is the brightest.
